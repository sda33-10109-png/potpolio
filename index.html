첨부된 파일 목록

GitHub에 올리고 나만의 웹사이트 만들기

이 프로그램을 **GitHub Pages**에 올리면 무상으로 24시간 언제 어디서나 접속 가능한 포트폴리오 웹사이트를 가질 수 있습니다!

1

GitHub 저장소 (Repository) 생성

GitHub.com 로그인 후 오른쪽 상단 [+] -> [New repository] 클릭. 이름(예: my-portfolio)을 입력하고 Public으로 만듭니다.

2

index.html 파일 업로드

만든 저장소 화면에서 [uploading an existing file] 링크를 누르고, 이 웹페이지 소스 파일을 **index.html** 이름으로 저장한 뒤 커밋(Commit changes)합니다.

3

GitHub Pages 기능 활성화

저장소 상단 메뉴의 **Settings** -> 왼쪽 **Pages** 메뉴로 이동합니다. Branch 항목을 main (또는 master)으로 선택하고 **[Save]**를 클릭합니다.

4

완료! 내 나만의 사이트 주소 생성

1~2분 후 https://사용자아이디.github.io/my-portfolio 주소로 웹 앱에 바로 접근할 수 있습니다!

데이터 보안 안내: 작성한 모든 생기부 정리 내용과 첨부된 PPT/이미지 파일은 인터넷 서버로 전송되지 않고 본인 컴퓨터/모바일 브라우저 내부에 저장됩니다. 다른 디바이스로 옮길 때는 상단 **[백업 내보내기/복원]** 버튼을 활용하세요.
