GitHub Pages 1분 배포

  1. GitHub.com 로그인 후 New Repository 생성
  2. 저장소 이름 작성 후 Public으로 설정하고 Create 클릭
  3. Add file -> Create new file 클릭하여 파일명을 index.html로 지정
  4. 이 웹페이지의 전체 HTML 소스코드를 붙여넣고 Commit changes 저장
  5. Settings -> Pages 탭 이동 후 Branch를 main으로 설정하고 Save 클릭하면 배포 웹 URL 완성!
